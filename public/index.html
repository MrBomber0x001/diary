نسخ احتياطية كاملة

تتضمن قاعدة البيانات والصور والملفات الصوتية لكل الحسابات.

تُحفظ كأرشيف ZIP محلياً في data/backups، مع الاحتفاظ بآخر ٧ نسخ كاملة. يعمل الجدول عند تشغيل التطبيق.

نسخة سحابية على AWS S3

ارفع نسخاً من الصور والصوت والنسخ الاحتياطية إلى حاويتك الخاصة.

تُحفظ الملفات محلياً وتُرفع نسخة إلى S3 بعد التفعيل. استخدم بيانات اعتماد AWS على الخادم عبر متغيرات البيئة أو IAM Role؛ لا تُدخل المفاتيح السرية هنا. يحتاج الدور إلى صلاحيات s3:ListBucket وs3:PutObject وs3:DeleteObject.

استعادة ZIP تستبدل قاعدة البيانات والصور والصوت بعد إنشاء أرشيف أمان. ملفات SQLite القديمة تستعيد قاعدة البيانات فقط. الحد ١ غيغابايت.
